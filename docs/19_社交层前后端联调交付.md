# 19 · 社交层前后端联调交付

> 目标：把「共同经历的事实」翻译成「关系的温度」。工具负责把人凑到一起，社交感来自把凑到一起之后发生的事**留下来、亮出来、再点燃**。
> 本轮把已批准方案里的 P0/P1/P2 全部落地（三个待拍板红线项未动），前后端已联调，全部证据见 `artifacts/screenshots/social/`。

## 二、红线自查

- 缺口卡与落地页：无身份、无报名进度、无池内人数；`失败无痕迹` 文案落在页脚。
- 破冰包：仅成员可见（403 非成员）、仅确认态之后；同课事实成局后才出现。
- 时间线：仅双方可见，无评分、无公开墙；回忆录分享文案不含搭子身份。
- 群聊：系统卡一次性、Lulu 开场一次后闭嘴；不优化消息数。
- 复局「安静结束」：单方静默，其他成员无通知。
- 三个待拍板项（Pooling 活性信号 / 兴趣可见时机提前 / 主理人栏目页公开度）**未实施**，等产品决策。
