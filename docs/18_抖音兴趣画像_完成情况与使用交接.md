**用户抖音扫码 → 后台采集「喜欢」并生成画像 → 落库 + 同步用户标签 → iOS 可见；可选答 3–5 道 JSON 题 → AI 再精修；画像参与匹配，成局后成员可见兴趣 chips。**

## 3. 用户怎么用（产品路径）

```text
App「我」→ 抖音兴趣画像
  → 开始导入（扫码）
  → 等待采集 / 分析（状态轮询）
  → READY：先有一份可用画像
  → [自动或手动] 答 3–5 道细化题（服务端 JSON）
  → 提交 → 「AI 正在精修…」
  → 精修后的画像（calibrated=true）
  → 可随时：刷新 AI 文案 / 删除 / 重新导入
```

本人在「我」页也能看到摘要；成局后队友在局成员列表看到兴趣 chips。

## 5. 关键 JSON 约定

### 5.1 画像结果（统一）

用于：`GET /profile/taste/me`、`POST .../answers`、`POST .../ai-refresh`、`import.result`

重点字段：

- `primary_tag` / `secondary_tags` / `interest_domains` / `interest_facets`
- `summary` / `persona` / `matching_hints`
- `calibrated` / `confidence` / `visibility`（默认 `members`）
- `sample.generation`：`llm` | `rule`

### 5.2 细化题包（taste-quiz-v1）

```json
{
  "schema_version": "taste-quiz-v1",
  "import_id": "imp_…",
  "intro": "根据你的喜欢内容，选 3–5 道题…",
  "min_answers": 3,
  "max_answers": 5,
  "optional": true,
  "calibrated": false,
  "submit_path": "/profile/imports/imp_…/answers",
  "questions": [
    {
      "id": "q_refine_…",
      "type": "single_choice",
      "prompt": "…",
      "required": true,
      "options": [{"id": "…", "label": "…"}]
    }
  ]
}
```

iOS：渲染 `questions` → 收集 `{question_id, option_id}` → POST `answers` → 展示返回的精修画像。

## 6. 数据落在哪

| 位置 | 内容 |
|---|---|
| `taste_import_sessions` | 任务状态、二维码、进度、题目、答案、result 快照 |
| `taste_profiles` | 用户当前画像（主键 user_id） |
| `profiles.self_reported_tags` | 同步的 `taste:*` 键（匹配用） |
| `profiles.interest_domains` | 兴趣域标签文案 |
| `profiles.capability_vector` | `taste:*` 分数分量 |
| runtime 目录 `runtime/douyin/{import_id}/` | 采集 items（Cookie 不进 API/DB 画像） |

删除画像：`DELETE /profile/taste/me/douyin` 会清 session + taste_profile + `taste:*` 标签。

## 9. 红线（仍有效）

1. 不接抖音开放平台 OAuth ClientKey  
2. Cookie / session 禁止出现在 API、日志、画像结果  
3. 手机号/验证码仅内存处理；DB 只存脱敏  
4. 不写 `verified_tags`（课表核验标签）  
5. AI 仅 Flash；失败降级 `generation=rule`，任务仍可 READY  
6. 可见性默认 `members`（匹配 + 成局后成员），不是匿名全站广播
