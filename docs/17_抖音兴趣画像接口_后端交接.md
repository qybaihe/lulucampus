# 抖音兴趣画像接口 · 后端 / 客户端交接

> 状态：**已跑通**（扫码登录 → 采集喜欢 → 内容打分 → DeepSeek V4 Flash 文案 → READY 画像）  
> OpenAPI：`openapi/onemore.openapi.json`（`taste_profile` tag）  
> 模块：`onemore/modules/taste_profile/`

---

## 1. 产品链路（给对接同学）

```text
创建任务
  → 展示二维码（可刷新）
  → 用户抖音扫码确认
  → [可选] 新设备手机号验证码
  → 自动识别账号 + 采集喜欢列表
  → 分析画像（内容打分 + OpenCode DeepSeek V4 Flash 文案）
  → 状态 READY，calibrated=false   ← 此时 /profile/taste/me 已有可用画像
  → [可选] 3–5 道领域细化题
  → READY，calibrated=true
```

**关键语义：**

| 点 | 说明 |
|---|---|
| 画像何时可用 | **采集分析结束立即可用**，不阻塞在选择题 |
| 选择题角色 | **可选细化**，只调子兴趣/表达方式，不是交叉验证 |
| AI 做什么 | 只生成 `summary` / `persona` / `interest_facets` / `matching_hints` |
| 标签分数 | 确定性规则打分，可复现、可测 |
| Cookie | 只在任务 runtime 目录，**永不进 API / 日志 / 最终画像** |
| 入库与匹配 | READY 后写入 `taste_profiles` + 同步到用户 `Profile`（`taste:*` 标签、interest_domains、capability_vector） |
| 可见性 | `visibility=members`：本人随时可见；**成局后成员 / 搭子关系**可见兴趣 chips |
| 匹配 | 相似匹配增加 `taste` 维度（兴趣标签 + 领域 Jaccard） |

## 2. 推荐客户端主流程

### 最短路径（主链路）

```http
# 1) 一步创建并尽量等到二维码
POST /profile/imports/douyin/qr?wait_seconds=10
X-User-ID: <user_id>
Content-Type: application/json

{"max_items": 0, "force": false}

# 2) 展示 data.qr_image_data_url 或 data.qr_image_url
#    轮询扫码/登录状态
POST /profile/imports/{import_id}/verify?wait_seconds=2

# 3) 轮询任务直到 READY / FAILED / CANCELLED
GET /profile/imports/{import_id}
# meta.poll_after_seconds 建议 2

# 4) 画像已就绪
GET /profile/taste/me
```

### 新设备手机号分支

当 `status` 为 `QR_SCANNED` / `PHONE_REQUIRED` / `WAITING_SMS_CODE`：

```http
POST /profile/imports/{import_id}/phone/code
{"phone": "13800138000", "country_code": "86"}

POST /profile/imports/{import_id}/phone/verify
{"code": "123456"}

POST /profile/imports/{import_id}/verify
```

### 可选细化题（iOS 原生 JSON 问答）

```text
READY 后：
  GET /profile/imports/{id}          → data.questions 内嵌 quiz JSON（未校准时）
  或 GET /profile/imports/{id}/questions

iOS 渲染 questions[]（single_choice）
  → 用户选择
  → POST /profile/imports/{id}/answers  { answers: [{question_id, option_id}, ...] }
  → 服务端：规则打分 + AI（DeepSeek V4 Flash）按答题再精修文案/facets
  → 返回统一 TasteProfileResultView（calibrated=true）
```

Quiz JSON 包（`schema_version=taste-quiz-v1`）字段：

```json
{
  "schema_version": "taste-quiz-v1",
  "import_id": "imp_…",
  "intro": "根据你的喜欢内容，选 3–5 道题…",
  "min_answers": 3,
  "max_answers": 5,
  "optional": true,
  "calibrated": false,
  "submit_path": "/profile/imports/imp_…/answers",
  "candidate_tags": [{"key":"…","label":"…","score":0.3}],
  "questions": [
    {
      "id": "q_refine_ai_programming",
      "type": "single_choice",
      "prompt": "…",
      "required": true,
      "options": [{"id":"ai_agents","label":"…"}]
    }
  ]
}
```

提交：

```http
POST /profile/imports/{import_id}/answers
{
  "answers": [
    {"question_id": "q_refine_ai_programming", "option_id": "ai_agents"},
    {"question_id": "q_refine_career_growth", "option_id": "projects_competitions"},

```

### 仅刷新 AI 文案（不重新扫码）

```http
POST /profile/taste/me/ai-refresh
```

复用最近一次 READY 任务的本地 `items.jsonl`，调用 OpenCode Go · `deepseek-v4-flash`。

## 3. 接口清单

### 3.1 任务 / 登录

| Method | Path | 说明 |
|--------|------|------|
| POST | `/profile/imports/douyin` | 创建任务 `202`，后台起浏览器 |
| POST | `/profile/imports/douyin/qr` | 创建并尽量等到二维码（推荐） |
| GET | `/profile/imports/{id}` | 轮询任务全量状态 |
| GET | `/profile/imports/{id}/qr` | 取当前二维码 |
| GET | `/profile/imports/{id}/qr/image?v=` | PNG 图片，`Cache-Control: no-store` |
| POST | `/profile/imports/{id}/qr/refresh` | 刷新二维码 `202` |
| POST | `/profile/imports/{id}/verify` | 查询是否已登录 |
| POST | `/profile/imports/{id}/phone/code` | 发短信验证码 |
| POST | `/profile/imports/{id}/phone/verify` | 提交验证码 |
| GET | `/profile/imports/{id}/phone` | 手机号验证状态 |
| POST | `/profile/imports/{id}/cancel` | 取消并清理 |

### 3.2 数据 / 画像

| Method | Path | 说明 |
|--------|------|------|
| GET | `/profile/imports/{id}/items` | 分页喜欢条目（调试/可选） |
| GET | `/profile/imports/{id}/questions` | 可选细化题 3–5 道 |
| POST | `/profile/imports/{id}/answers` | 提交细化答案 → 覆盖画像 |
| GET | `/profile/taste/me` | 当前用户画像；无则 `null` |
| POST | `/profile/taste/me/ai-refresh` | Flash 重写文案 |
| DELETE | `/profile/taste/me/douyin` | 删除抖音画像与任务产物 |

### 3.3 兼容摘要

`GET /profile/me` 增加可选字段 `taste_profile`：

```json
{
  "primary_tag": {"key": "explorer_builder", "label": "探索型 Builder"},
  "secondary_tags": ["知识策展人", "审美观察者"],
  "summary": "...",
  "confidence": 0.65
}
```

**不要**写入 `verified_tags`。

## 4. 状态机

| 状态 | 客户端动作 |
|------|------------|
| `PREPARING_QR` | 展示 loading |
| `WAITING_SCAN` | 展示二维码；可 refresh / cancel |
| `QR_SCANNED` | 提示已扫码，可能要手机号 |
| `PHONE_REQUIRED` | 引导输入手机号 |
| `WAITING_SMS_CODE` | 输入验证码 |
| `AUTHENTICATED` | 已登录，继续等 |
| `RESOLVING_PROFILE` | 识别账号中 |
| `COLLECTING` | 可用 `progress` / `collection` 展示进度 |
| `ANALYZING` | 生成画像中（含 AI 文案） |
| `READY` | **成功终态**；读 `result` 或 `/taste/me` |
| `QR_EXPIRED` | 点刷新二维码 |
| `FAILED` | 展示 `error.code` / `error.message` |
| `CANCELLED` | 可重新创建 |

`NEEDS_CONFIRMATION` 为旧遗留态，新链路**不再进入**。

## 7. AI 能力说明（DeepSeek V4 Flash）

| 项 | 值 |
|----|-----|
| Provider | OpenCode Go |
| Endpoint | `https://opencode.ai/zen/go/v1/chat/completions` |
| Model | **`deepseek-v4-flash` only** |
| 实现 | `onemore/modules/taste_profile/llm_enrich.py` |
| 触发时机 | ① 分析完成后自动；② `POST /profile/taste/me/ai-refresh` |
| 失败策略 | 降级规则摘要，`sample.generation=rule`，任务仍 `READY` |
| 测试环境 | `ONEMORE_ENV=test` 自动关闭外呼 LLM |

> 密钥与模型已按产品要求**写死在抖音画像能力模块内**，不走通用 LLM 配置切换到其他模型。

## 10. 客户端伪代码

```typescript
// 1. 创建 + 拿二维码
const { data } = await api.post('/profile/imports/douyin/qr?wait_seconds=10', {
  max_items: 0,
  force: false,
});
const importId = data.import_id;
showQR(data.qr_image_data_url || data.qr_image_url);

// 2. 轮询直到 READY
while (true) {
  const s = await api.get(`/profile/imports/${importId}`);
  if (s.data.status === 'READY') break;
  if (s.data.status === 'FAILED' || s.data.status === 'CANCELLED') throw s.data.error;
  if (s.data.status === 'QR_EXPIRED') await api.post(`/profile/imports/${importId}/qr/refresh`);
  if (['PHONE_REQUIRED', 'QR_SCANNED'].includes(s.data.status)) {
    // 引导手机号验证...
  }
  await sleep((s.meta?.poll_after_seconds ?? 2) * 1000);
}

// 3. 读画像（也可用 s.data.result）
const taste = await api.get('/profile/taste/me');
renderProfile(taste.data); // summary / persona / tags / facets

// 4. 可选：细化题
const qs = await api.get(`/profile/imports/${importId}/questions`);
// 用户答完后
await api.post(`/profile/imports/${importId}/answers`, { answers });
```

## 11. 红线

1. 不接抖音开放平台 OAuth / ClientKey / ClientSecret  
2. Cookie / session 值禁止出现在 API、日志、DB 画像  
3. 手机号与验证码仅线程内存处理；DB 只存脱敏手机号  
4. 抖音标签 **不写** `verified_tags`  
5. 画像默认 `visibility=members`（用于匹配与成局后成员展示；Cookie 仍禁止出库）  
6. AI 仅 Flash；不可静默切换到其他模型  
7. 删除画像时同时清掉 `taste:*` 用户标签与匹配向量分量
