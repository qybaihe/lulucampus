# Skill 2 · 抖音兴趣画像（独立可体验）

把抖音主页变成一张兴趣画像卡：主标签、子兴趣、人格化描述、成局提示。  
**本压缩包不含抖音 Cookie、不含 API Key。**

## 评委怎么体验（推荐，不用解压）

1. 打开 https://luludrawu.classby.cn  
   或扫描本目录 `评委体验二维码.png`
2. 在抖音 App：我 → 右上角分享 → 复制链接  
   得到 `v.douyin.com/...` 或 `www.douyin.com/user/MS4wLjAB...`
3. 粘贴到体验页，生成画像卡，可导出 PNG

你贴的是**对方主页的分享链接**，不是你的登录态。拉公开主页数据时，服务端用的是部署环境里的运营 Cookie；那份 Cookie **只在云端环境变量，从未打进这个 zip**。

## 两条产品入口

| 入口 | 谁扫 / 谁贴 | Cookie 在哪 |
|---|---|---|
| 体验页贴分享链接 | 评委贴任意公开主页链接 | 云端 `DOUYIN_COOKIE`，本包没有 |
| App 内抖音扫一扫 | 用户用自己的抖音扫码 | 用户自己的登录，走浏览器会话，不进仓库 |

本地无 Cookie 时，后端 `ONEMORE_DOUYIN_MODE=fake` 仍可走通整条状态机（见 `app-module/providers/fake.py`）。

## 本包是什么

独立 Skill：Agent 拿到一条抖音主页分享链接，调用已部署接口（或不带 Cookie 的 fake 分析器），产出结构化画像。不依赖噜噜 App 登录。

```
SKILL.md                      Agent 加载入口
scripts/analyze-from-link.mjs 调用线上接口，本机零 Cookie
edge-demo/                    EdgeOne 落地页 + 云函数源码
app-module/                   App 内导入 / 扫码 / 分析器源码
.env.example                  空占位，禁止填写后回传到 git
```

## 本地调线上接口（仍不需要 Cookie）

```bash
node scripts/analyze-from-link.mjs "https://v.douyin.com/xxxxxxxx/"
```

默认打 https://luludrawu.classby.cn/demo/taste/from-link 。Cookie 在服务端，脚本只传分享链接。
