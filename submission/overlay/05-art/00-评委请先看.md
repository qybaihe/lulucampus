# 美术资产 · 噜噜 IP 与设计稿

当前产品 IP 是**噜噜**（厨房系白边贴纸风），不是早期阿凑 / AIIA 粉发稿。本包只放终稿与可用母版。

## 建议打开顺序

1. `design/mobile-prototype/SCREEN_CONTACT_SHEET.png` — 36 屏总览
2. `design/lulu-frontend/export/index.html` — 噜噜前端交互稿
3. `design/lulu-frontend/export/DESIGN-HANDOFF.md` — 还原契约
4. `ip/brand/` — 图标与 lockup
5. `ip/atlases/` — 业务状态精灵表（已去掉厨房专用废图）
6. `readme-assets/` — README 用的产品主视觉
7. `cast/` — 测试剧组头像

## 不含

- `lulu/generated/` 生图中间帧
- `design/generated/imagegen-*` 过程稿
- 历史阿凑 / 粉发候选（避免评委认错 IP）
- 设计稿 `raw/` 重复导出（只保留 export + 原型 screens）
