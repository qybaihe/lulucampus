## 10 分钟启动（假校园、真成局）

```bash
cp .env.example .env
docker compose up --build
docker compose exec api uv run onemore-seed
```

- API：http://127.0.0.1:8000/docs
- Web：`cd web && yarn && yarn dev`
- 剧组登录：手机号 `13900001001`–`006`，密码 `cast-onemore`
- 开发头：`Authorization: Bearer dev:u_demo_1`

`ONEMORE_HERMES_MODE=fake` 时不碰校园系统，成局状态机可完整走通。
