# Skill 1 · SYSU Anything（校园行动引擎）

这是噜噜成局「今天」Tab / Hermes 的执行底座：把中大分散在教务、雨课堂、图书馆、场馆、班车、岐关、就业、学工里的能力，收成 Agent 可调用的一层。

## 10 秒理解

Agent 不手写爬虫。它加载本目录的 `skills/sysu-anything-cli/SKILL.md`，按白名单调用 `sysu-anything` CLI。写操作默认预览，只有用户明确确认才加 `--confirm`。

## 目录

```
skills/sysu-anything-cli/     Agent Skill（跨平台）
skills/sysu-anything-apple/   macOS 日历 / 提醒闭环
src/                         CLI 源码
dist/                        已编译，可直接跑
bin/                         npm bin 入口
data/bus-schedule.json       广州校区班车离线时刻
install/                     Codex / AI IDE 安装脚本
```

## 怎么跑（只读、免登录）

```bash
node dist/cli.js --help
node dist/cli.js bus --help
node dist/cli.js qg --help
```

课表、场馆、研讨室等需要用户自己的校园登录。本包**不含**任何 `.sysu-anything` 会话或 Cookie。

## 和噜噜成局的关系

Hermes 把自然语言编成 Action Schema，再转成上述 CLI argv（`shell=False`）。凭证进 Vault，用完销毁。详见产物 `03-Agent-Workflow-噜噜成局.zip`。
