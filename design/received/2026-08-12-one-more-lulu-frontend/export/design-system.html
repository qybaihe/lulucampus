01概念

产品性格决定视觉姿态。三条产品性格，各对应一条视觉翻译。

最小单元是「一个局」

所以界面的主角是席位与缺口，不是人。签名组件是圆桌席位图——你看的永远是「这件事还差什么」。

AI 越早退场越好

所以 Lulu 只在有事发生时出现：在听、在想、办成了、要走了。它不做装饰性常驻，不刷存在感。

凑不齐就安静结束

所以视觉低刺激、有呼吸感。亮色暖调，不喊。失败态没有红色、没有归因、没有惩罚性文案。

缺口 = 明黄，全屏最高视觉权重

「还差一个」用明黄实心 + 脉冲。任何页面同一时刻只允许一个缺口焦点。红色禁止用于缺口——红被读作错误，而缺口是邀请。

已就位 = 深墨绿黑实心

「已具备 / 已就位」用墨色实心。两种状态形状相同、填充相反，色盲用户也能凭「亮 vs 暗」区分，不只靠色相。

04栅格与形状

4pt 基线网格；页面左右边距 20px；卡片间距 12px；段落留白 24–40px。

圆角

8 小件 · 14 输入 · 20 卡片 · 28 弹层 · 999 行动按钮与胶囊

描边

1px 常规 · 2px 强调（意图卡、最紧急 DDL）· 不用投影堆层级

触控

命中区 ≥ 44pt · 主行动按钮高 52pt · 列表行高 ≥ 48pt

密度

一屏一个问题。页面空的时候用信息结构承担重量，不用头像墙和热度数字填。

05组件

核心组件在原型中全部为可运行实例。以下为签名组件「圆桌席位」的两种形态。

圆桌席位 · Seat Table

详情页全尺寸（240pt）：圆桌居中，席位环绕。已就位 = 墨色实心；缺口 = 明黄 + 1.6s 脉冲呼吸。列表页用紧凑席位条（26pt 圆点）。

VoiceOver 朗读：「数学建模国赛冲刺：2 人已就位，缺 1 人 · 写作位」。

缺口徽章 Gap Badge

明黄胶囊 + 等宽数字。全屏同语义唯一来源，禁止用普通标签仿制。

行动按钮

主行动 = 明黄底墨字胶囊；次级 = 墨描边；三级 = 纯文字。一屏最多一个主按钮。

状态视图 State View

G5 八态共用同一骨架：Lulu + 一句影响 + 一个动作。见原型 M10 → 界面状态规范。

不做

不做等级成长、不喂养、不签到、不主动搭话。事情办完就退场（exit.bow 是产品叙事的句号）。

减弱动效

系统开启「减弱动态效果」时，全部状态降级为 poster 静帧（manifest 中 reducedMotionPolicy: poster-frame）。

07贴纸素材库 · 36 张

半写实手绘卡通 · 统一光照 · 主体带约 5% 连续白边 · 512×512 透明 PNG · 表面留白不写字。新素材沿用同一风格回源生成。

08动效原则

时长

微反馈 160ms · 页面过渡 280ms · 曲线 cubic-bezier(0.22, 1, 0.36, 1)。没有超过 300ms 的界面动效。

缺口脉冲

1.6s 呼吸外扩环，只用于缺口席位。它是全产品唯一循环播放的非 Lulu 动效。

Lulu 帧率

≤12fps 手绘帧感。切帧不位移（双锚点对齐）。once 剪辑停在 poster 帧，不鬼畜循环。

09Dynamic Type 与 VoiceOver

Dynamic Type 放大思路

字号阶梯整体随系统缩放（基准 17px 正文）。放大到 AX 级时：圆桌席位从环形布局降级为纵向列表（席位语义不变）；卡片由多列降为单列；底部 Tab 只留图标 + 文字加大行高；缺口徽章数字允许换行但不缩小。所有滚动容器不锁高度。

VoiceOver 思路

圆桌席位朗读为「N 人已就位，缺 M 人 + 缺口角色」，不逐个点名；缺口席位在焦点顺序中排最前；Lulu 动效标记为装饰性（decoractive），其状态语义由旁边文案承担；所有贴纸带角色 alt（如「后卫（缺口）」）。

10设计侧红线（不可协商）

以下在任何页面、卡片、浮层、通知、空态、异常态中都不得出现。出现即为设计错误。
